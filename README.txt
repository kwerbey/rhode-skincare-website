RHODE-INSPIRED SKINCARE WEBSITE
=================================

FILES:
- index.html       = Home/shop page
- about.html       = About page
- style.css        = All website styling
- script.js        = Button/cart interactions
- images/          = Put your own images here

IMAGE REPLACEMENT:
1. Put your own image files inside the "images" folder.
2. The homepage expects:
   - hero.jpg
   - product1.jpg
   - product2.jpg
   - product3.jpg
   - routine.jpg
3. The About page expects:
   - about.jpg

If your image has a different filename, edit the matching
<img src="images/FILENAME.jpg"> in the HTML.

HOW TO RUN:
1. Open index.html in Chrome.
2. Bootstrap loads from the internet through the CDN.
3. If you use Notepad++, edit and save the files, then refresh Chrome.

NOTE:
This is a school-project concept site inspired by a minimalist
beauty/skincare layout. Replace placeholder images with images
you are permitted to use.
